# UI 图标使用规范

## 目标

界面中的常用工具操作优先使用小图标表达，减少重复文字和控件宽度，让顶部工具栏、卡片操作区和高频页面保持简洁。图标统一复用全局 `app-icon` 组件及 `src/assets/icons/lucide/` 中的公共资源，不在页面内自行绘制或复制图标；资源目录名为历史兼容保留。整套公共资源统一使用 Khushmeen Sidhu 的 Doodle Icons 黑白手绘图标包（个人和商业使用免费、无需署名），并针对当前语义色与小尺寸显示做适配。

在含义清晰且已有共享图标可用时，默认使用图标，不再显示同义文字。新增短文字按钮、角标或状态提示前，应先检查 `app-icon` 是否已有可准确表达的图标；这条原则同时适用于常用操作和锁定、完成、提醒等通用状态。只有存在歧义、属于业务专有概念或操作后果需要明确说明时，才保留可见文字。

## 图标来源

- Doodle Icons 是业务界面默认且唯一的图标来源。每次需要图标时，先查项目公共资源；项目内没有时，默认继续检索 Doodle Icons 完整原库，而不是自行生成一个新图标。
- 所有新增和替换的业务图标都必须来自 Khushmeen Sidhu 的 Doodle Icons 原始图标包，禁止自行绘制、仿制、拼接 SVG 路径，也禁止混用其他图标库。
- 添加图标前，先检查 `app-icon` 和 `src/assets/icons/lucide/` 是否已有对应资源；没有时，再从 Doodle Icons 原包查找并将原始 SVG 纳入公共资源目录。
- 禁止使用文字字形、Unicode 符号或 Emoji 代替视觉图标，例如 `★`、`☆`、`♥`、`♡`、`×`、`⚙`。如果这些符号承担的是操作或状态图标语义，必须改用 `app-icon` 中的 Doodle Icons 资源；普通正文内容不受此限制。
- 只允许为小程序显示做必要的文件名、画布、冗余元数据、语义颜色和反色版本适配，不得修改原图标的路径造型。
- 如果原包没有语义准确的图标，保留清晰文字或先确认替代方案，不得自行补画一个“同风格”图标。

## 优先使用纯图标的场景

当操作含义常见、单一，并且图标已经形成稳定认知时，使用纯图标按钮，不再在图标旁重复添加文字。例如：

- 设置、返回、关闭、更多。
- 新增、编辑、删除。
- 搜索、筛选、刷新、下载、打印。
- 图片预览、上传图片、清除内容等常用工具操作。

推荐写法：

```xml
<view
  class="settings-button"
  role="button"
  aria-label="人生节点设置"
  bindtap="handleSettings"
><app-icon name="settings-2" size="28" /></view>
```

不要同时显示设置图标和“设置”文字，也不要用字符、Emoji 或页面内临时 SVG 代替已经存在的公共图标。

## 必须保留文字的场景

以下内容不能为了追求简洁而强行改成纯图标：

- 图标含义不明确、属于业务专有概念，或用户需要猜测其作用。
- Tab、筛选项、表单字段、布局选项等需要明确区分含义的内容。
- 登录、保存、提交、确认支付等需要清晰表达结果的主要操作。
- 同一区域出现多个外形相近、难以仅靠图标区分的操作。

有歧义时优先保留短文字；图标简洁不能以理解成本为代价。

## 尺寸与可访问性

图标尺寸使用独立于字体的视觉规格，不与 `20rpx / 23rpx / 25rpx` 字号一一绑定，也不通过文字字号推导。统一按图标在界面中的职责选择：

| 层级 | 尺寸 | 使用场景 |
| --- | --- | --- |
| 微型指示 | `16rpx` | 文字旁的非交互方向、展开等辅助指示 |
| 紧凑辅助 | `24rpx` | 密集卡片、次要状态、紧凑工具栏中的辅助图标 |
| 常规默认 | `27rpx` | 列表、设置项、表单附属操作和普通图标按钮 |
| 重点强调 | `30rpx` | 顶部主要操作、底部导航和需要成为视觉重点的状态或操作 |

- 公共图标只使用四级标准尺寸：大号 `30rpx`、中号 `27rpx`、小号 `24rpx`、微型 `16rpx`。不要为相邻控件随意引入 `17rpx`–`23rpx`、`25rpx`、`26rpx`、`28rpx`、`29rpx` 等近似尺寸。
- 大号 `30rpx` 用于底部导航、页面顶部主要工具操作，以及需要成为当前区域视觉重点的图标。
- 中号 `27rpx` 是常规默认尺寸，用于列表项、设置项、表单附属操作、复制按钮和进入箭头等普通业务控件。
- 小号 `24rpx` 用于密集卡片中的次要操作、紧凑工具栏和辅助状态；不得为了容纳更多控件而缩小点击区域。
- 微型 `16rpx` 是图标的最小尺寸，只用于紧凑控件内部、与文字搭配的非交互辅助指示，例如范围选择按钮中的下拉箭头。不得用于独立图标按钮、主要操作、列表项图标或需要单独辨认和点击的图标。
- 纯图标按钮必须提供准确的 `aria-label`，不能只依赖视觉图形传达含义。
- 非交互状态图标不需要扩展为按钮点击区，但状态含义必须进入所在控件的 `aria-label`，视觉图标本身应对辅助技术隐藏，避免重复朗读。
- 图标尺寸与点击区域相互独立，纯图标按钮的点击区域不得小于 `56rpx × 56rpx`。
- 紧凑工具栏中的图标按钮应保持一致的点击区域、对齐方式和视觉重量。
- 深色按钮使用反色图标；颜色继续遵循 `docs/ui-colors.md`，不得在页面样式中硬编码。
- 图标按钮不额外使用固定文字宽度；如必须显示文字，则按内容宽度加均衡的左右内边距。
