# UI 基础样式规范

## 核心标准

全局核心文字字号为 `25rpx`，通过 CSS 变量 `--ui-font-size-base` 使用。
`page` 已默认继承该字号；组件内需要显式声明字号时，统一引用这个变量。

适用范围：

- 常规正文与列表内容
- 功能入口和选项文字
- 表单输入、选择器与文本域
- 主要、次要和危险操作按钮
- 搜索、筛选和工具栏中的文字操作
- 空状态与常规反馈文案

推荐写法：

```less
font-size: var(--ui-font-size-base);
```

## 允许的层级差异

- 页面标题、卡片标题、分组标题和关键统计数字可以大于 `25rpx`。
- 标签、角标、时间、字数、字段说明和辅助元信息可以小于 `25rpx`，但必须明确属于次要信息。
- 仅用于图标造型的字符字号不受本规范限制。
- 新增普通文字时，若没有明确的标题或辅助信息语义，默认使用 `25rpx`。

## 检查原则

判断一个字号是否应当偏离 `25rpx` 时，先确认它是否属于标题、关键数字、辅助说明或图标；否则应回到核心字号。

## 行高与垂直居中

- 正文、列表文字和字段内容通常使用 `1.4` 至 `1.6` 的行高。
- 固定高度的按钮、选项和操作胶囊统一使用 Flex 居中：`align-items: center` 与 `justify-content: center`。
- Flex 只能居中文字行盒，`line-height: 1` 会把行盒压得过紧，并放大字体自身上下留白不对称的问题。
- 包含正常文字的 Flex 控件应使用 `line-height: normal`；不要再通过 `translateY`、负边距或额外上下内边距修正文字位置。
- 只有纯图标、箭头、加号、单字占位标记等图形化字符可以使用 `line-height: 1`。

文字按钮推荐写法：

```less
display: flex;
align-items: center;
justify-content: center;
line-height: normal;
```

## 圆角层级

圆角根据组件尺寸和用途选择，不要求所有组件使用相同数值。首页功能豆腐块是标准内容卡片，使用 `22rpx`，其他组件以它为参照按层级增减。

- 微型标签、角标和紧凑内容块：通常使用 `8rpx` 至 `10rpx`。
- 输入框、选项、小图标底块等控件：通常使用 `12rpx` 至 `16rpx`。
- 常规列表卡片、功能入口和内容卡片：使用 `22rpx`。
- 信息较多的大面板、个人资料卡和登录卡：使用 `24rpx`。
- 居中弹窗和强浮层：使用 `32rpx`。
- 胶囊按钮使用自身高度的一半；需要完全胶囊化时使用 `999rpx`。
- 正圆头像、圆形按钮和状态点继续使用 `50%`。

全局变量：

```less
--ui-radius-small: 14rpx;
--ui-radius-card: 22rpx;
--ui-radius-panel: 24rpx;
--ui-radius-modal: 32rpx;
--ui-radius-pill: 999rpx;
```

检查圆角时优先判断组件属于小控件、标准卡片、大面板、弹窗还是胶囊；不要为了统一数值破坏组件自身比例。

## 页面左右间距

普通单栏页面的标准左右安全边距为 `32rpx`，通过 `--ui-page-gutter` 使用。它与 `22rpx` 标准卡片圆角搭配时，能让卡片边缘与屏幕之间保持足够呼吸感。

- 首页、设置、详情、编辑、打印等普通单栏页面：使用 `32rpx`。
- 带固定侧边栏的窄内容区：可以使用紧凑边距 `24rpx`，通过 `--ui-page-gutter-compact` 使用。
- 登录页、居中品牌卡片等需要更强聚焦的布局，可以大于 `32rpx`。
- 弹窗内边距、卡片内边距和页面安全边距不是同一概念，应根据内容密度单独确定。
- 同一页面中的标题、卡片和主要操作区域应共享同一条左右对齐线。

推荐写法：

```less
padding-right: var(--ui-page-gutter);
padding-left: var(--ui-page-gutter);
```

## 弹窗尺寸

- 标准确认弹窗使用 `32rpx` 圆角，屏幕左右间距使用弹窗专用的 `56rpx`，不能直接沿用普通页面的 `32rpx`。
- 标准双按钮弹窗最低高度为 `420rpx`，不能只依靠短文案自然撑高。
- 弹窗采用标题、正文、操作区三段式布局：标题固定在距顶部 `48rpx` 的位置，不能随正文行数上下移动。
- 弹窗正文区域使用 Flex 占据中间剩余空间并上下居中；正文左右内边距为 `48rpx`，文本阅读区最大宽度为 `440rpx` 并水平居中。
- 操作按钮固定在底部，操作区左右内边距为 `40rpx`，底部保留 `44rpx` 安全间距。
- 文案较多时弹窗可以继续向下增长；最低高度只解决短文案状态，不应设置固定高度截断内容。
- 弹窗标题建议使用 `32rpx`，正文和按钮保持全局核心字号 `25rpx`。
